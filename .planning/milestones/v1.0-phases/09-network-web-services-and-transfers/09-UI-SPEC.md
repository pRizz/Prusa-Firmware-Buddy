# Phase 09 - UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

Phase 9 preserves user-visible network surfaces for IFCE-02 and IFCE-03. The UI oracle is the existing PrusaLink/WUI static bundle in `src/resources/web`, the embedded WUI selectors and handlers under `lib/WUI`, the transfer status/error surfaces in `src/transfers`, and inherited on-device GUI entry/status surfaces from Phase 8.

This phase owns PrusaLink/WUI local web UI/API affordances, auth and credential entry surfaces, transfer/download status and error surfaces, Connect registration/service entry surfaces inherited from Phase 8, static WUI asset compatibility, and visible network service status. It must not create marketing pages, redesign the PrusaLink web app, redesign transfer concurrency, add new cloud features, or claim final cutover evidence.

## Typography

WUI typography has exactly two weights: regular `400` and bold `700`. Do not add web fonts, intermediate weights, viewport-scaled text, or a new typography system. Local on-device surfaces inherit the Phase 8 bitmap font contract.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | `.txt-md` / `1rem`: `14pt` desktop, `32pt` narrow | 400 | 1.5 |
| Label | `.txt-sm` / `.75rem`: `10.5pt` desktop, `24pt` narrow | 400 | 1.5 |
| Heading | `.txt-md` / `1rem`: `14pt` desktop, `32pt` narrow | 700 | 1.5 |
| Display | `.txt-lg` / `1.25rem`: `17.5pt` desktop, `40pt` narrow; job progress may use existing `40px` override | 700 | 1.5 |

Exceptions: toast headers preserve the bundled `line-height: 1.25`; graph labels preserve the bundled `10.5pt`; local Connect registration, QR, PrusaLink password, and header transfer/status surfaces inherit Phase 8 bitmap cell dimensions.

## Copywriting Contract

All WUI web copy must stay sourced from the existing static bundle and `data-label` localization keys. All on-device copy must stay localization-backed through `N_(...)`, `_(...)`, or the existing translation provider path. Do not add English-only copy, secrets, certificate bytes, tokens, passwords, private keys, or raw crash dump contents to manifests or UI fixtures.

| Element | Copy |
|---------|------|
| Primary CTA | Preserve by surface: WUI API-key gate `Login`; local Connect menu `Add Printer to Connect`; local setup prompt `Set up Prusa Connect?`; WUI file section `Upload file` |
| Empty state heading | WUI telemetry/job placeholders stay `NA`; no-transfer and no-job API states stay hidden or `NoContent` as in source; local Wi-Fi scan empty state stays `Scanning...` on MINI and `Scanning for networks...` on large display |
| Empty state body | Local credential wait flow preserves `Please insert a flash drive with a network configuration file.` and the existing PrusaSlicer generation sentence from Phase 8 |
| Error state | WUI fallback errors preserve `API error` / `Cannot connect to printer` and `Application error` / `Something bad happened on application side`; local network error preserves `No network interface` plus the existing module/restart/ethernet recovery body; Connect registration maps source errors such as DNS, TLS, auth, server, internal, network, and protocol failures to the existing registration failure surface |
| Destructive confirmation | Preserve source confirmations for stop print, delete file/folder where shown by WUI, `Delete credentials INI file? (Recommended)`, and Connect registration abort `Prusa Connect setup is not finished. Do you want to exit and abort the process?` |

Transfer-specific visible error copy must preserve existing localized source strings, including `File removed or transfer aborted`, `File transfer error`, `The path does not exist`, and the slow G-code transfer warning text. API status bodies may be JSON/status-code behavior rather than rendered text; the WUI must continue to map them through the existing toast/offline/error components.

## Interaction and State Rules

| Rule | Contract |
|------|----------|
| Server resource model | The WUI contract must include streaming parsing, active/idle connection distinction, limited active connections, shared send buffers, generated parser automata, and graceful refusal of unsupported protocol behavior. Do not model WUI as a generic large web server. |
| Auth modes | Manifest and Rust contracts must distinguish WUI digest auth, API-key auth, empty/disabled credential behavior, nonce/stale behavior, and API-key full-match behavior. Secret values are named-only evidence. |
| Endpoint families | Use endpoint-family rows for PrusaLink API v1, OctoPrint-compatible API, USB/file handlers, static assets, previews, unknown request, SNTP, mDNS, metrics, and syslog unless a child endpoint has materially different visible or error behavior. |
| Transfer model | Preserve the single active transfer slot across Connect commands, WUI upload/transfer endpoints, monitor status, recovery, encrypted AES-CTR payload metadata, range handling, and storage preconditions. Transfer concurrency redesign is out of scope. |
| Error mapping | Preserve source status-code and JSON/no-content behavior for `/api/v1/job`, `/api/v1/status`, `/api/v1/transfer`, `/api/v1/files`, OctoPrint-compatible `/api/*`, and upload handlers; WUI rendered errors must continue through existing toast/offline/modal components. |
| Static asset compatibility | The WUI manifest must record static asset filenames, content source, gzip/embed ownership, and source paths. Do not regenerate or replace the web app in Phase 9 unless a plan explicitly owns asset parity evidence. |
| Responsive behavior | Preserve the source CSS breakpoint, burger animation, desktop horizontal nav, modal centering, max content width, sticky telemetry, and text wrapping/word-break behavior. |
| Local GUI inheritance | Phase 9 may extend service semantics for Connect/PrusaLink surfaces, but visual geometry, font, color, copy, and display-class behavior remain bound to the approved Phase 8 UI-SPEC. |

## Manifest Row Contract

Every Phase 9 UI-relevant manifest row must declare:

| Field | Required Contract |
|-------|-------------------|
| `requirement_id` | `IFCE-02` for Connect/TLS/telemetry/transfer integration; `IFCE-03` for PrusaLink/WUI/API/local services |
| `surface` | One of `connect-registration`, `connect-status`, `wui-static-assets`, `wui-auth`, `wui-api-family`, `wui-storage-files`, `transfer-status`, `transfer-error`, `network-header-status`, `network-status-menu`, `metrics-syslog`, `sntp-mdns`, or a stricter source-backed child |
| `reference_sources` | Exact source paths under `src/resources/web`, `lib/WUI`, `src/connect`, `src/common/http`, `src/transfers`, `src/gui`, `src/common/metric*`, `src/logging`, or `src/syslog` |
| `visible_behavior` | Short user-visible behavior statement, including copy/status/progress/error affordance when the surface renders UI |
| `auth_requirement` | `none`, `digest`, `api-key`, `connect-token`, `credential-display`, or `named-only-secret` |
| `integration_point` | Storage, transfer monitor, Connect registration, TLS/proxy, static asset, metric/syslog, SNTP/mDNS, or local GUI boundary |
| `evidence_class` | One of `manifest-check`, `source-audit`, `static-source-audit`, `host-test`, `rust-host-test`, `simulator-flow`, `hardware-smoke`, or `manual-hardware-required` |
| `proof_scope` | `local` only for deterministic static/source/Rust/verifier proof; simulator, hardware, live cloud, physical network, USB/media races, long-running transfers, and cutover proof are `non-local` unless actually run |
| `intentional_delta` | `none`, `approved`, or `blocked`; custom DER certificate fixes, proxy changes, transfer behavior changes, or auth behavior changes require explicit delta rows and regression evidence |
| `secret_handling` | `none` or `named-only-redacted`; never include token/password/certificate/private-key/crash-dump byte values |
| `phase_lifecycle_id` | `9-2026-06-14T02-15-21` |

Required manifest files are `phase9_connect_contracts.json`, `phase9_wui_contracts.json`, `phase9_transfer_contracts.json`, `phase9_network_service_contracts.json`, and `phase9_network_concern_dispositions.json`.

## Overclaim and Evidence Contract

| Evidence Area | Contract |
|---------------|----------|
| Local green claims allowed | Manifest shape, source-path existence, Rust domain constructors/state transitions, parser/error classification, redaction rules, WUI static asset inventory, and host/verifier tests that actually run locally |

# Phase 08 - UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

Phase 8 preserves local printer GUI parity for IFCE-01. The existing C++ firmware GUI is the oracle: `src/gui`, `src/guiapi`, `src/gui/dialogs`, `src/gui/menu_item`, `src/gui/footer`, `src/gui/wizard`, `src/gui/resolution_240x320`, `src/gui/resolution_480x320`, and `src/gui/guimain.cpp`.

This phase owns local GUI entry surfaces only. Network service behavior is Phase 9, auxiliary runtime behavior is Phase 10, and full cutover/display acceptance evidence is Phase 11 unless a narrow local GUI fixture is explicitly recorded.

## Typography

Bitmap font sizes are character cell dimensions, not CSS point sizes. Line height is the exact bitmap cell height; multiline rectangles must allocate `N * height(Font::role)` plus only source-backed padding.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | `Font::normal`: `11x18` MINI, `11x19` large | regular bitmap role; large display maps to the existing bold resource asset | `1.0` bitmap cell |
| Label | `Font::special`: `9x16` on both display classes | regular | `1.0` bitmap cell |
| Heading | `Font::big`: `11x18` MINI, `13x22` large | bold | `1.0` bitmap cell |
| Display | `Font::large`: unavailable on MINI, `30x53` large; use `Font::big` on MINI | bold | `1.0` bitmap cell |

Allowed weights: regular and bold only. Do not add intermediate weights, antialiasing variants, scalable web fonts, or viewport-scaled text.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000000` (`COLOR_BLACK`) | Screen background, menu background, default window background, unfilled display regions |
| Secondary (30%) | `#FFFFFF` (`COLOR_WHITE`), `#C0C0C0` (`COLOR_SILVER`), `#808080` (`COLOR_GRAY`), `#5B5B5B` (`COLOR_DARK_GRAY`) | Primary text, focused menu background, disabled labels, progress tracks, large-display clickable icon normal state |
| Accent (10%) | `#F8651B` (`COLOR_ORANGE`) | Selected/focused radio buttons, progress fills, active print-control animation, warning/action attention lines, Connect registration underline, value edit emphasis |
| Destructive | `#E74626` (`COLOR_RED_ALERT`) | Redscreen, BSOD, fatal/error alert backgrounds, and destructive warning surfaces only |

Accent reserved for: active selection, focused radio state, progress fill, warning/action emphasis, Connect-registration underline, print-control animation, and edited numeric/text values. Accent must not be used as a general decoration or as a replacement for ordinary white text.

## Copywriting Contract

All user-facing strings must stay localization-backed through `N_(...)`, `_(...)`, or the existing translation provider path. Do not add English-only copy to Phase 8 manifests or Rust domain fixtures.

| Element | Copy |
|---------|------|
| Primary CTA | `Print` for print preview; conditionally `Continue` when tool mapping will show, matching `RadioButtonPreview` |
| Empty state heading | `Scanning...` on MINI and `Scanning for networks...` on large display for empty Wi-Fi scan lists |
| Empty state body | `Please insert a flash drive with a network configuration file.` for the INI credential wait flow; preserve the existing second sentence about PrusaSlicer generation |
| Error state | `No network interface` with the existing module-missing/restart-or-use-ethernet recovery body |
| Destructive confirmation | Stop print: `Are you sure to stop this printing?`; Connect registration abort: `Prusa Connect setup is not finished. Do you want to exit and abort the process?`; crash dump warning: preserve the existing USB-save prompt and sensitive-information warning |

Home-screen entry labels are `Print`, `Preheat`, `Filament`, `Control`, `Settings`, `Info`, and `No USB`. Print preview secondary action is `Back`.

## Firmware GUI Contract

### Display Classes

| Display Class | Source Selector | Contract |
|---------------|-----------------|----------|
| MINI | `DISPLAY_TYPE_MINI`, `HAS_MINI_DISPLAY()` | Fixed `240x320`; ST7789 path; footer stays visible in menus; print controls use 64px icons; print preview uses horizontal/default radio behavior from the 240x320 implementation. |
| Large | `DISPLAY_TYPE_LARGE`, `HAS_LARGE_DISPLAY()` | Fixed `480x320`; ILI9488 path; menu footer disabled; print controls use 80px icons; print preview uses header, thumbnail, vertical 94px button rail, phone/QR Connect registration layout, and larger dialog geometry. |
| Mock | `DISPLAY_TYPE_MOCK`, `HAS_MOCK_DISPLAY()` | Test-only display class; may verify layout math and unit-test behavior but must not be recorded as physical LCD proof. |

### Interaction States

| Surface | Required Behavior |
|---------|-------------------|
| Screen stack | Preserve `MAX_SCREENS = 16`, pending-open behavior, close/close-all/close-printing flags, timeout controls, and `gui_loop_until_dialog_closed` responsiveness from `ScreenHandler`. |
| Screen allocation | Preserve fixed-storage screen creation from `ScreenFactory`; no heap-backed or dynamically sized screen model may be claimed as parity without an intentional-delta row. |
| Dialog mapping | Preserve `DialogHandler` FSM mapping for wait, safety timer, load/unload, preheat, selftest, network setup, printing, crash recovery, warning, print preview, cold pull, phase stepping, input shaper, belt tuning, gearbox, door sensor, manual belt tuning, and loadcell failure screens when feature gates enable them. |
| Print controls | Preserve print, serial print, pause/resume/cancel/stop, reprint, and preview workflows. Stop actions must ask the source warning confirmation before aborting. |
| Setup workflows | Preserve network setup, selftest, calibration, first-layer, load/unload, cold pull, and wizard frame behavior through source-backed manifest rows. |
| Connect registration entry | Preserve only the local dialog, QR/code layout, abort confirmation, status text, and registration entry surfaces. Token, TLS, telemetry, WebSocket, and service semantics remain Phase 9. |
| Localization | Layout fixtures must include translated-text capacity, truncation/rolling behavior, font/resource visibility, and display-class-specific copy width. Do not embed credential, token, certificate, or crash-dump bytes. |
| Error and warning surfaces | Preserve redscreen, BSOD, watchdog, hardfault, stack overflow, fatal warning, QR error, crash dump warning, and ordinary warning/info/error message boxes as named local GUI surfaces. |

### Manifest Rows

Every Phase 8 manifest row must declare:

| Field | Required Contract |
|-------|-------------------|
| `requirement_id` | `IFCE-01` unless a later requirement is explicitly cross-referenced as out-of-scope evidence |
| `display_classes` | `240x320`, `480x320`, or both; do not let one class imply the other |
| `reference_sources` | Exact source paths under the C++ GUI oracle |
| `reference_behavior` | Short behavior statement tied to source or fixture identity |
| `rust_surface` | `buddy-domain` GUI type, verifier row type, or adapter boundary |
| `evidence_class` | One of `manifest-check`, `source-audit`, `static-source-audit`, `host-test`, `rust-host-test`, `simulator-flow`, `hardware-smoke`, or `manual-hardware-required` |
| `proof_scope` | `local` only for static/source/Rust/verifier proof; simulator, hardware, timing, touch, and long-run behavior must be `non-local` unless actually run |
| `intentional_delta` | `none`, `approved`, or `blocked`; fixes to reference defects require an intentional-delta row and regression evidence |

Required manifest files are `phase8_gui_workflows.json`, `phase8_display_layouts.json`, and `phase8_concern_dispositions.json`.

### Known Concern Contract

`CL-008` must be represented as a first-class GUI/error-flow contract: the home screen can remain active with events disabled when a flash action fails to start. Phase 8 must either preserve the reference behavior with explicit evidence or declare an approved intentional delta that proves no-op flash action handling and event re-enable behavior.

The crash dump warning surface must preserve the local prompt and sensitive-information warning while leaving crash dump transport/security behavior to the Phase 6 and Phase 9 boundaries.

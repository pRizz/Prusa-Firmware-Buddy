## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest strings -> Rust domain types | Raw Phase 10 evidence classes, proof scopes, row IDs, states, firmware image sources, update modes, Modbus identities, MMU transport states, dock identities, and fault classes are parsed into typed contracts. |
| Firmware resource/prebuilt identities -> typed values | Firmware image facts are represented by named paths or CMake variables only, not payload bytes or signing material. |
| Product profile facts -> auxiliary controller availability | Auxiliary controller contracts must be derived from validated `ProductProfile` and feature facts, not unchecked strings or unconditional availability. |
| Pure domain -> future adapters | Domain contracts describe compatibility facts but do not perform live Modbus, RS485, MMU, firmware update, filesystem, simulator, or hardware effects. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

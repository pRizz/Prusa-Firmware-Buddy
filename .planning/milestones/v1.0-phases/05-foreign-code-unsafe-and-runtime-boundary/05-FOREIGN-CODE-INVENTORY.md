## Deferred Behavior Parity

Printing-core, persistence/resource compatibility, GUI workflows, network service behavior, transfers, and auxiliary-controller behavior are inventory-visible here but not implemented by Phase 5 Plan 01. The required evidence for those surfaces stays assigned to Phase 6 through Phase 10.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest strings -> Rust domain types | Raw Phase 9 evidence classes, proof scopes, row IDs, auth modes, command IDs, proxy modes, service surfaces, and transfer states are parsed into typed contracts. |
| Secret-bearing identities -> typed values | Token/password/certificate/transfer key facts are represented by named identities only, not value material. |
| Pure domain -> future adapters | Domain contracts describe compatibility facts but do not perform live network, filesystem, TLS, WUI, scheduler, or transfer effects. |
| Product feature facts -> service availability | Network services must be explicitly gated by `Feature::Connect` or `Feature::WebUi`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-01 | Tampering | `NetworkParityRowId` and command ID parsers | mitigate | Use fallible constructors rejecting empty, path-like, whitespace/control, and overlong IDs. |
| T-09-02-02 | Elevation of Privilege | `NetworkProofScope` with non-local evidence | mitigate | Reject `Local` proof scope for simulator, hardware, and manual evidence classes. |
| T-09-02-03 | Information Disclosure | `SecretHandling` and `EncryptedPayloadMetadata` | mitigate | Model named-only redaction and encrypted payload metadata without exposing token/password/certificate/key/IV byte getters. |
| T-09-02-04 | Spoofing | `ProxyMode` and Connect identity surfaces | mitigate | Encode proxy TLS-only/no-auth limitation and distinguish token config key, fingerprint header, and registration-code header identities. |
| T-09-02-05 | Denial of Service | Transfer range and slot state contracts | mitigate | Reject invalid ranges and keep single-slot states explicit for later adapter consumers. |
| T-09-02-06 | Elevation of Privilege | `NetworkServiceContract` | mitigate | Reject Prusa Connect without `Feature::Connect`; reject WUI/SNTP/mDNS/DNS/metrics/syslog without `Feature::WebUi`. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest files to verifier | JSON evidence rows are repo-authored input but still need schema, source-path, lifecycle, and payload-leak checks before being trusted as parity evidence. |
| Rust source to verifier | Verifier reads Rust files as text, so missing type names or unsafe code can otherwise pass silently. |
| Validation notes to verifier | Human-readable validation docs can accidentally claim non-local proof or leak payload/credential content unless scanned. |
| Verifier to subprocess | `--all` invokes local cargo commands and must avoid shell injection or hardware/simulator side effects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03-01 | Tampering | `tools/bazel/phase10_verify.py` manifest parsing | mitigate | Require exact manifest paths, exact row IDs, required fields, IFCE-06 requirement IDs, and lifecycle ID `10-2026-06-14T15-08-30`. |
| T-10-03-02 | Information Disclosure | Phase 10 manifests and validation notes | mitigate | Reject `firmware_payload`, `payload_bytes`, `hex_bytes`, `credential_value`, `private_key`, `SIGNING_KEY_VALUE`, `raw_crash_dump`, `crash_dump_payload`, and `BEGIN PRIVATE KEY`. |
| T-10-03-03 | Repudiation | Evidence proof scope | mitigate | Reject local proof claims for simulator, hardware, manual-only, RS485, MMU live-transport, toolchanger, long-running update, and final cutover evidence. |
| T-10-03-04 | Spoofing | `rust_surface` and retained source claims | mitigate | Require concrete Rust type names and retained source paths from D-01 through D-17; do not accept generic placeholder strings. |
| T-10-03-05 | Denial of Service | `--all` subprocess execution | accept | `--all` is local developer verification only and runs finite cargo commands without shell expansion or hardware access. |
| T-10-03-06 | Elevation of Privilege | Verifier command execution | mitigate | Use `subprocess.run` with argument lists, `shell=False`, no environment secrets, no network calls, and no simulator or hardware startup. |

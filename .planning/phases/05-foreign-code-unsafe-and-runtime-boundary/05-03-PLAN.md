## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| domain profile -> runtime adapter | Validated product profiles select startup, linker, task, and allocator contracts. |
| runtime adapter -> retained startup/FreeRTOS/panic code | Rust contracts describe retained C/C++/ASM runtime behavior without changing it. |
| host tests -> scheduler/hardware behavior | Host tests verify contract logic, not interrupt timing or scheduler behavior on MCU hardware. |

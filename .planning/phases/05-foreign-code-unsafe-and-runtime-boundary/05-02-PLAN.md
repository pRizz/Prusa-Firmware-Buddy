|----------|-------------|
| domain profile -> board adapter | Validated domain values enter board/HAL/MMIO/DMA contracts. |
| board adapter -> retained HAL/CMSIS/ASM/vendor code | Typed Rust contracts describe retained board surfaces before any raw pointer or FFI call. |
| local contract tests -> hardware behavior | Host tests verify constructors and allowed unsafe locality only. |

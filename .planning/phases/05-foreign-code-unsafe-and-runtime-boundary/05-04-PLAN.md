## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| domain/runtime contract data -> FreeRTOS reference surfaces | Typed Rust contracts describe retained FreeRTOS task and synchronization behavior without changing C/C++ wrappers. |
| host tests -> scheduler timing | Host tests verify contract construction and evidence classification only; wakeup timing and scheduler ordering need simulator or hardware evidence. |
| task readiness -> subsystem startup | Later subsystem code will depend on task dependencies, event bits, queues, timers, mutexes, and semaphores modeled here. |

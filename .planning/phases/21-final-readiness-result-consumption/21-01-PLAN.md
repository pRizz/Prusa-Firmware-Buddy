## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream-results JSON -> Phase 18 verifier | Untrusted machine-readable result rows cross into final readiness gating. |

| T-21-02 | Tampering | upstream manifest/artifact refs | mitigate | Validate repo-relative paths and approved external roots per result family; reject absolute paths, parent traversal, and refs outside `build/ci-evidence/phase19/`, `build/ci-evidence/phase20/`, `external://phase19/`, or `external://phase20/`. |
| T-21-03 | Repudiation | exception-approved maintainer decisions | mitigate | Require exceptions to cite affected upstream row ids and mitigation; hard blockers for malformed input, lifecycle mismatch, source-ref failure, path/root failure, redaction failure, and overclaim failure remain non-coverable. |
| T-21-04 | Information Disclosure | upstream input and generated consumption artifacts | mitigate | Extend existing forbidden field/text scans to upstream result input and `upstream-result-consumption.json`; reject private keys, tokens, credentials, raw firmware payloads, crash dumps, and secret-bearing fields. |
| T-21-05 | Elevation of Privilege | `demotion_allowed` computation | mitigate | Compute final readiness from the combined maintainer decision gate and upstream result gate; generated overclaim guards reject `demotion_allowed=true` unless both validated inputs allow it. |
| T-21-06 | Denial of Service | malformed upstream JSON | mitigate | Parse JSON once at the boundary, require object/list shapes and bounded field types, and fail with explicit verifier errors instead of partial readiness output when `--upstream-results` is supplied and invalid. |

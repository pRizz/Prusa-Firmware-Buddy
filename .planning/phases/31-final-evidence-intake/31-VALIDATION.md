| Property | Value |
|----------|-------|
| **Framework** | Python `unittest` invoked as a script |
| **Config file** | none - phase tool tests are plain Python files under `tools/bazel/` |
| **Quick run command** | `python3 tools/bazel/phase31_final_evidence_intake_test.py -q` after Wave 0 creates the test file |
| **Full suite command** | `just phase31-verify` after Bazel/root/just wiring |
| **Estimated runtime** | less than 90 seconds based on Phase 23-28 verifier patterns |

## Sampling Rate

- **After every task commit:** Run `python3 tools/bazel/phase31_final_evidence_intake_test.py -q` plus the specific verifier mode being touched, such as `--contract-only`, `--security-only`, or `--wiring-only`.
- **After every plan wave:** Run `just phase31-verify` once the Bazel/root/just wiring exists.
- **Before `/gsd-verify-work`:** `just phase31-verify` must be green.
- **Max feedback latency:** 30 seconds for focused Python tests after Wave 0; 90 seconds for the full `just phase31-verify` phase gate on a warm cache.

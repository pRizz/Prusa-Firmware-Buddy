<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator/release manager input to Phase 31 CLI | Untrusted JSON packets and retained-output paths cross into local verification. |
| Phase 31 to Phase 23-26 validators | Phase 31 delegates stream-specific validation through subprocess calls and must not alter proof semantics. |
| Phase 31 retained outputs to Phase 32 | Accepted receipts and rejected-submission reports become downstream triage inputs. |
| Release/signing evidence refs | Secret-bearing release evidence must remain external refs or digests, never retained raw material. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | Spoofing | Finality policy | mitigate | Require `real_*_evidence_supplied: true`, non-empty `submitter_identity_ref`, Phase 23-26 validator command refs, and retained manifest plus upstream row proof before `accepted-final`. |
| T-31-02 | Tampering | Artifact refs and output dirs | mitigate | Reject absolute paths, parent traversal, bare external roots, symlink output escapes, and refs outside `build/ci-evidence/phaseXX/` or `external://phaseXX/`. |
| T-31-03 | Repudiation | Receipt provenance | mitigate | Store packet SHA-256, validator command, validator output refs, consumed upstream row refs, generated timestamp, stream, requirement IDs, and finality status in each receipt. |
| T-31-04 | Information Disclosure | Secret-bearing evidence packets | mitigate | Reuse Phase 23-26 forbidden field/text patterns and add Phase 31 guard checks before any accepted receipt writes; retain refs, digests, redaction summaries, and artifact-reference summaries only. |
| T-31-05 | Denial of Service | Malformed or incomplete packets | accept | Malformed final packets fail closed with explicit rejected-submission reasons; no availability guarantee is required for bad local inputs. |
| T-31-06 | Elevation of Privilege | Readiness/demotion implications | mitigate | Do not write readiness, demotion, cutover verdict, retained-code acceptance, residual-risk acceptance, or maintainer approval fields; keep Phase 31 receipts separate from Phase 33-35 decisions. |
| T-31-07 | Tampering | Row-only or prose-only evidence | mitigate | Reject upstream-row-only, summary-only, prose attestation, local smoke, template-only, and quick/default paths unless the underlying retained manifest and packet validation are revalidated through Phase 23-26. |
</threat_model>
